## Goals

- Practice Data Structures & Algorithms consistently
- Keep solutions organized and easy to review
- Record real problem-solving progress
- Build a searchable interview-preparation reference

## Recommended Solution Format

Each solution should include:

1. Problem name and link
2. Approach
3. Time complexity
4. Space complexity
5. Clean implementation

## Contribution Workflow

LeetCode solutions can be synchronized automatically using a supported sync tool such as LeetSync. Only actual solved problems should be added; no synthetic commits are intended.
