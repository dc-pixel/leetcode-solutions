# Contributing Solutions

This repository is intended to contain genuine LeetCode practice and solution notes.

## Adding a solution

For each accepted problem, include:

- The problem name and LeetCode link
- The chosen approach
- Time complexity
- Space complexity
- A clean, runnable implementation

Keep one problem per solution file and use a descriptive filename. Do not add placeholder, duplicate, or synthetic solutions solely to increase repository activity.

## Organization

Use the difficulty directories (`Easy`, `Medium`, and `Hard`) when practical. Topic directories such as `Arrays`, `Strings`, `Dynamic-Programming`, and `Graphs` can be used when they improve discoverability.

## Automated sync

If using a LeetCode-to-GitHub synchronization tool, verify that the generated solution corresponds to an actual accepted submission before committing it.
